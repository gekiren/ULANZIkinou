# Changelog

All notable changes to the Ulanzi Deck plugins in this repository will be documented in this file.

## [1.1.0] - 2026-08-30
### Added
- `mastervolume`: Added active window volume control functionality.

## [1.0.0] - Initial Release
### Added
- Initial release of the following plugins:
  - `apprestart` (App Restart)
  - `pcsleep` (PC Sleep)
  - `displaytoggle` (Display Toggle)
  - `lineincontrol` (Line In Control)
  - `mastervolume` (Volume Control)
  - `videofullscreen` (Video Fullscreen)
